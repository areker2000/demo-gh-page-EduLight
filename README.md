# EduLight - 線上家教選課平台

> **從 UI/UX 設計到前端開發實踐**
> 
> [Live Demo](https://areker2000.github.io/demo-gh-page-EduLight/) | [Figma WireFrame](https://www.figma.com/design/3vaFJpeHWlYw9leUmn3nKr/EudLight-WireFrame?t=ruA9yumrCgfZdZmo-1) | [Figma Prototype](https://www.figma.com/proto/3vaFJpeHWlYw9leUmn3nKr/EudLight-WireFrame?node-id=5-10&p=f&t=ULjZbvjdZsoQfGzS-1&scaling=scale-down&content-scaling=fixed&page-id=5%3A8&starting-point-node-id=5%3A10)

## 建構流程
1. 使用Figma繪製初步Wireframe與製作Prototype
2. AI輔助建立基本概念模板並確立風格，根據最終風格在提高使用者體驗之目的下微調版面設計
3. 使用Vite + React建立架構與邏輯處理
4. 整合TypeScript，加強程式編碼嚴謹性


## 技術要點

### 1. 現代化工具鏈整合
- **Vite + React構建程式並優化**
- **TypeScript嚴格型別，維持程式嚴謹架構**
- **以Axios串接前後端API，維持資訊真實與完整性並貼近實際應用情形**

### 2. 複雜狀態管理
- 運用 **React Hooks (useContext)** 封裝登入狀態、讀取狀態與全站共用資料，實現跨組件的狀態同步，並確保組件渲染效能

### 3. 工程化規範
- **ESLint & Prettier**：嚴格執行程式風格檢查
- **Git Flow**：維持清晰的 Commit Message 與版本更迭記錄
